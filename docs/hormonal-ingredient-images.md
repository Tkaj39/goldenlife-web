# Woman Hormonal Balance — nové obrázky aktivních látek

Šest dodaných originálních PNG je v assets/hormonal-ingredients/. Dlouhý produktový popis obsahuje 12 nových URL: šest karet a šest detailů. URL jsou připnuté na neměnný Git commit s obrázky, ne na staré obrázky ani na neprovedený upload do Shoptetu. Původní texty, CSS, skripty, horní banner a krátký popis zůstávají beze změny.

Základ: main 609ec14bf1e819c58e5c046a0d4d7da78bc97c5a. Obrázkový commit: 5dd1235ce41d44711ab617ee475213dfd094c4d1.

GitHub main není totéž co uložený popis v Shoptetu: pokud e-shop nemá automatické nasazení, je nutné uložit aktuální HTML z této větve v editoru dlouhého popisu. V rámci tohoto úkolu se neukládá nic do administrace e-shopu.

Původní zdravotní tvrzení nebyla tímto schválena; zejména účinky na hormonální rovnováhu, výkyvy nálad a vstřebatelnost vyžadují samostatné ověření. Podklady: brand/RULES.md, dodaná stránka a šest *_luxusni_v3.png. Žádná nová obrazová generace.
